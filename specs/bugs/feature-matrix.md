# Feature matrix

Checkout: `zeus-bot/bug-ledger`, which is `codex/integration-20261111` at `2722dcb7` plus this ledger. States are from that tree unless a row names another commit. This VM cannot run the Mac app, so **works** is not used. A control with a real path and only contract or fixture tests is **partial**. A control that refuses the action the person asked for is **broken**. A page or type with no app caller is a **stub**.

Device end-to-end is **none** unless a row names a journey that drives the real control on a Mac. Native fixtures and `swift test` filters are named in the state cell when they exist. They are not device proof.

The known playback failure is logged as ZB-026 and owned by `zeus-bot/media-playback-control`. That branch was not on `origin` when this matrix was written.
