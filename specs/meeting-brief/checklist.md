# Checklist: Meeting brief and prompt

- [x] Shared, presenting, or unknown capture collapses the brief.
- [x] Contacts denial omits role and company.
- [x] History stores a hash, a date, and a short title.
- [x] Notes are plain and truncated.
- [x] Domain match is exact. An empty list treats everyone as external.
- [x] The log line is a count only.
- [x] Off-device stays off.
- [x] The prompt appears only inside a 5 to 10 minute lead, default 5.
- [x] The line is "Your meeting with X starts in N min. See it?"
- [x] Expanded detail hides purpose, context, role, company, and Join while the screen is shared or a meeting app is presenting.
- [x] Join is absent without a link.
