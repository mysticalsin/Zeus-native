# Gap matrix: companion parity

Citations are line numbers on integration head `2722dcb7497d5415fbc1fcb1f65c49629966a281` (`codex/integration-20261111`). They were taken by reading those lines. This matrix does not say that any row has been run.

"The reference companion" is the studied open-source cursor buddy (public README and architecture notes, MIT). Behaviors are described in Zeus's own words. No source from that project is copied, and this tree does not name it.

**State** means what the integration head contains:

- `exists` — the behavior is in the source.
- `partial` — a piece is in the source and the experience Tony asked for is not closed.
- `missing` — the source has no implementation of that behavior.

`exists` is not a proof. The proof column names the test a later slice must add. Nothing in this folder is that test.

## Top 10 gaps by what Tony would feel

These are the rows that decide whether a hold feels instant and trustworthy. R39 is reserved for the other study. This plan only schedules the swap hook.

1. **R6 and R7.** Time from releasing the key to the first word of audio. The source can split sentences and stream some voices. The experience is still not one gate that refuses to wait for the full answer and the full audio file.
2. **R37.** The listening face waits until the microphone session returns. The hold cannot feel instant until the lamp is tied to the key event.
3. **R12.** Numbered marks exist as a layout type and an accessibility label. Nothing creates them, and the canvas does not paint them, so Zeus cannot point at "the second button" the way a teacher would.
4. **R8.** A second hold stops several objects in sequence. There is no single interrupted phase, so speech, the pointer, and the capture can disagree.
5. **R10 and R9.** A capture that is denied or empty is an empty list. The model can be asked about a screen Zeus did not see, or the turn can go quiet.
6. **R27.** The cursor buddy is hidden from VoiceOver. Marks would be announced if any existed. The buddy itself is silent.
7. **R22.** Screen-share hiding and a privacy page exist. The notch does not light a mic lamp and a capture lamp for the turn.
8. **R19 and R20.** Face matching and instant commands are local. Nothing yet is the one policy that keeps face unlock and those controls up when the network and every model are absent.
9. **R38.** The display link can follow 60 Hz or 120 Hz and can sleep. Nothing counts a dropped frame while Zeus is speaking.
10. **R39, with R34.** The orb and the Jarvis persona are not in the tree. They stay unfilled until the orb study replaces the marked section. The only work this plan schedules is a `Persona` protocol whose default is the current mascot and whose orb conformance stays off.

R17 and R36 (memory that dies at quit) are the next gap after these ten. R23 (the hold is not taught on first launch) follows them.
