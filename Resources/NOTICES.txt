## Laya (decision engine)
- Code: https://github.com/NandhaKishorM/laya, Apache License 2.0. Pinned commit
  55a19f7b7b56787e1a3e41063def9bb9a8737351 (used at build time to export ONNX graphs; the
  System One request shape ZEUS sends is the public wire format, no Laya code is compiled in).
- Weights: https://huggingface.co/convaiinnovations/laya-multilingual (default, mmBERT-base,
  322M) and https://huggingface.co/convaiinnovations/laya (English, ModernBERT-large, 421M),
  Apache License 2.0. Fetched only from the official convaiinnovations Hugging Face org.
- Upstream encoders: mmBERT (JHU CLSP, MIT) and ModernBERT (Answer.AI and LightOn, Apache 2.0),
  as declared by the checkpoints.

## Speech tools (run on this Mac, not bundled)
whisper.cpp (MIT), faster-whisper (MIT), Kokoro (Apache-2.0): run from the person's machine
when they set them up. Never bundled inside ZEUS.

## Insomnia (ideas only, no code)
Keep-awake battery and heat rules, and lid-closed mode ideas (a user-scoped sudoers rule for
pmset disablesleep and lowpowermode, a recovery journal written before every change, a launchd
backstop, freezing chosen apps, mute, Low Power on battery, hotspot handoff and tmux nudges),
inspired by Insomnia (MIT, Krish Garg; fork by mysticalsin). Zeus's code is its own.

## browser-use (ideas only, not bundled)
Indexed browser actions inspired by browser-use (MIT, Gregor Zunic)

## Browser agent (ideas only, no third-party code)
ZeusCore/BrowserAgent/BrowserAgentLoop.swift is Zeus's own code. Its design borrows ideas from:
- browser-use and jev-ultrafast (MIT): a fixed op enum acting on numbered page elements, one
  model round trip per step that names the op and its target, a DOM element list rather than
  screenshots, a freshness check (page-state id) before any input, and capped waits.
- typesafe-computer-use (MIT, awlevin): the model picks, code checks the facts, execution is
  deterministic; stop on done, low confidence, a stall or the step limit instead of guessing.

## agent-desktop (idea only, no code)
Drive snapshot refs inspired by agent-desktop (Apache-2.0, Vercel)

## Fast path and "Hey Zeus" (ideas only, no third-party code)
- hassil, Home Assistant's intent parser (https://github.com/OHF-Voice/hassil, Apache License 2.0):
  the `(a|b) [optional] {slot}` sentence-template idea behind ZeusCore/Intent/IntentTemplates.swift.
  Zeus's matcher and templates are written from scratch.
- Home Assistant intents (https://github.com/OHF-Voice/intents, CC BY 4.0) and Rhasspy
  (https://github.com/rhasspy/rhasspy, MIT): ideas for phrasing coverage only; no sentence data copied.
- openWakeWord (https://github.com/dscripka/openWakeWord, code Apache License 2.0, pre-trained
  models CC BY-NC-SA 4.0): the idea of gating recognition behind voice-activity detection. Its
  models are not used or shipped (non-commercial licence; a "Hey Zeus" model would also need its
  Python training pipeline). "Hey Zeus" uses Apple's on-device speech recognition instead.
- jev-voice-browser (MIT): debounce live partial transcripts (~200 ms) and start understanding on
  stable partials, so the action fires when the final transcript lands.
- jev-router (MIT): fail open on Jev errors, never act on a low-confidence answer, and the Engine
  setting chosen in Settings always wins.
- typesafe-computer-use (MIT): "the classifier picks, code decides the facts, then deterministic
  execution"; stop and ask instead of guessing.
- shpotify (https://github.com/hnarayanan/shpotify, no licence file found): AppleScript verbs for
  Spotify, as ideas only.

## Murmure pill orb (Sources/ZeusCore/Dictation/ThinkingOrbMath.swift, Sources/Zeus/Voice/ThinkingOrb.swift)
Dotted-sphere geometry loosely ported from thinking-orbs 0.3.2 (MIT License, Jakub Antalik,
https://libraries.dev/orbs). The "listening" state (a waveform rolling through latitude rings) and
"working" state (particles on tilted orbits) are reimplemented natively in SwiftUI (Canvas driven
by TickingView, no web view, no WebGL); no code from the package is compiled in.
